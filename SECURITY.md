# Security and privacy

Please do not report private data or credentials in a public issue. Contact the repository owner privately if you discover an exposed token, participant identifier, private metadata, or other sensitive material.

Before publishing a run, inspect:

- notebook outputs and embedded error messages;
- metadata, mapping files, and filenames;
- logs, Nextflow reports, and archive manifests;
- generated workbooks and figures;
- Git history, not only the current working tree.

Research data may require institutional approval, controlled access, or de-identification even when it contains no obvious names.
